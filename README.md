# Cynaris Internship 
## Week 3 – Day 4: Looker Studio Dashboard

**Objective:** Build an interactive dashboard using Google Looker Studio connected to Google Sheets.

### Dashboard Features

* Market overview and KPI scorecards.
* Historical stock price analysis.
* Risk and drawdown analysis.
* Trading patterns and sector analysis.
* Market trends and insights.
* Interactive filters and date range controls.
* Sector-wise performance comparison.

### Tools Used

* Google Looker Studio
* Google Sheets
* CSV datasets
* Data Visualization
* Data Analytics
